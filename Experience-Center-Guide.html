What Changed & What's New

Key renames, relocations, consolidations, and new features to be aware of.

Consolidated

One Console to Rule Them All

ZIA, ZPA, ZDX, Branch/Cloud Connector, Zero Trust Browser, Mobile Admin, Zero Trust for Workloads, and Risk 360 are all unified at console.zscaler.com. No more switching tabs or logging into separate portals.

Ep 1 @ 0:14
New Feature

Global Search with Aliases

The magnifying glass icon in the top bar lets you search for any feature by name. It supports aliases from the old consoles, so typing legacy names still finds the right page. Also shows you the navigation path.

Ep 6 @ 3:00
New Feature

One API (Unified API)

A new unified API endpoint replaces per-product API keys. Legacy APIs still work under Administration > API Configuration > Legacy API, but the One API consolidates access across all services.

Ep 5 @ 9:43
New Feature

New ZDX Dashboards

Experience Center includes brand new dashboards for Digital Experience that are unique to the new platform. Legacy dashboards remain accessible via the "Switch to Existing Reports" toggle.

Ep 5 @ 1:52
Consolidated

External Portals Eliminated

Client Connector Portal and Workflow Automation no longer open in separate browser windows. Everything is embedded within Experience Center under Infrastructure > Connectors > Client and Administration > Workflow Automation.

Ep 5 @ 8:06
Consolidated

RBAC Centralized in Zidentity

Role-based access control and administrator entitlements are now primarily managed through the Zidentity portal, rather than per-product admin consoles.

Ep 7 @ 4:58

Policies > DEM > Remote Execution

Relocated

Browser Access Moved to Clientless

ZPA Browser Access is no longer under Application Segments. It's now under the Clientless > Access Methods section in Experience Center.

Ep 4 @ 2:20
Relocated

ZPA App Protection policies moved from the ZPA section into the cross-product Cyber Security > Inline Security area.

Ep 4 @ 3:09

Ep 9 @ 6:40
New Feature

Per-OS Platform Settings

For Zscaler Client Connector, App Profiles now sit alongside a separate Platform Settings area broken out per operating system. Options like unattended-mode passwords and browser-based authentication are configured per platform under Infrastructure > Connectors > Client > Platform Settings.

Ep 8 @ 7:01
Retiring

Legacy Consoles Sunset

On April 1, 2026, legacy administrative UIs enter maintenance mode — configuration changes still work, but no new features are added and all new development is exclusive to Experience Center. Legacy UIs are deprecated on September 30, 2026. Migrate now.

Tips & Shortcuts

Make the transition smoother with these power-user tips.

🔎

Use the Search Bar

The magnifying glass icon in the Experience Center top bar is your best friend. It searches across all products and supports aliases from legacy console names. It also shows you the exact navigation path so you can bookmark it mentally.

Ep 6 @ 3:00   Ep 7 @ 9:07
⚡

Activation Still Required

In the Branch & Cloud Connector section, changes are not automatically applied. Look for the cloud-with-arrow icon in the top bar — that's your activation button. If you see "activation pending," you need to click it to push your changes live.

Ep 6 @ 6:15
📑

Legacy Reports Toggle

Under Analytics > Digital Experience, there's a "Switch to Existing Reports" checkbox. Enable it to see all your familiar legacy dashboards and reports while you get comfortable with the new native Experience Center dashboards.

Ep 5 @ 2:18
🔐

RBAC Lives in Zidentity Now

Don't hunt for role management in each product's admin section. Role-based access control and entitlements are now centralized in the Zidentity portal. Product-specific admin pages may link you there automatically.

Ep 7 @ 4:58
🚀

One API Is Coming

A new unified "One API" is replacing per-product API keys. Your legacy API keys still work under Administration > API Configuration > Legacy API, but start planning your migration to the One API for a single endpoint across all services.
